## 🚀 COMO USAR

### Opção A - Usar COM Explicações (RECOMENDADO):

1. Baixe TODOS os arquivos
2. Renomeie os arquivos `_COM_EXPLICACOES`:
   - `script_COM_EXPLICACOES.js` → `script.js`
   - `style_COM_EXPLICACOES.css` → `style.css`
   - Todos JSONs: `_COM_EXPLICACOES.json` → nomes originais
3. Abra `index.html`
4. **PRONTO!** Gabarito mostra explicações! 📚

### Opção B - Usar SEM Explicações (original):

1. Use os arquivos sem sufixo `_COM_EXPLICACOES`
2. Funciona normalmente, sem explicações

## 📖 TIPOS DE EXPLICAÇÕES

### 🌟 **Explicações DETALHADAS** (100 questões - Português 1 e 2):

```
📚 Explicação:
✓ CORRETO! INTERVIR deriva de VIR, não de VER. Pretérito de VIR = 
veio → INTERVEIO. 'Interviu' confunde com VER (viu) = ERRO. 
Conjugação: interveio, intervieste, interveio, interviemos, 
interviestes, intervieram. Sempre seguir VIR!
```

**Características:**
- 3-4 linhas completas
- Explica POR QUE está certo/errado
- Exemplos e regras gramaticais
- Comparações úteis

### 📝 **Explicações FUNCIONAIS** (500 questões - demais):
